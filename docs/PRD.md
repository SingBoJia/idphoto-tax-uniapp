## 1. 一句话

把证件照制作与个税计算两个独立工具合并成一个 uni-app 小程序，用户一次打开即可完成“拍照改尺寸”和“算税看明细”。

## 2. 目标

- 减少用户在两个小程序之间跳转。
- 保留两个工具的核心能力，不引入登录门槛。
- 一次开发，同时产出 H5 与微信小程序。
- 数据尽量在本机处理，降低隐私风险。

非目标：

- 不在本期重建证件照的登录、下单、支付、评价、第三方 AI 接口。
- 不做多商户、多城市、账号体系。
- 不做云端保存照片或收入数据。

## 3. 用户与场景

| 用户 | 场景 | 诉求 |
|---|---|---|
| 求职/考试用户 | 报名需要一寸、二寸、学信网等规格 | 快速换底色、改 KB、保存 |
| 上班族 | 想看工资个税、年终奖、劳务报酬 | 输入收入，立即看到税额与税后 |
| 家庭用户 | 需要赡养老人、子女教育等扣除 | 快速汇总专项附加扣除 |
| 普通用户 | 临时算一笔税或做一张证件照 | 不注册、不登录、即开即用 |

核心旅程：

1. 打开小程序 → 证件照 → 选规格 → 上传照片 → 换底色 → 生成 → 保存。
2. 打开小程序 → 个税 → 工资个税 → 填收入/五险一金/专项扣除 → 计算 → 看结果与税率表。
3. 个税 → 专项附加扣除 → 填各项 → 保存 → 自动带回工资表单。

## 5. 功能需求

### 5.1 首页（P0）

- 双功能卡片：证件照、个税。
- 快捷工具：修改 KB、换底色、自定义尺寸、个税速算。
- 使用说明与隐私提示。

验收：点击卡片进入对应 tab；快捷工具进入对应页面。

### 5.2 证件照列表（P0）

- 搜索规格名称/像素/毫米。
- 分类：全部、常用、证件、考试、自定义。
- 规格卡：名称、像素、毫米、热门标记。
- 常用工具入口。

内置规格：一寸、小一寸、大一寸、二寸、小二寸、大二寸、身份证、驾驶证、社保卡、学信网、计算机等级、教师资格证、护士执业资格、公务员、自定义。

验收：搜索“一寸”出现相关规格；点击规格进入编辑页并带上 specId。

### 5.3 证件照编辑（P0）

- 选择相册/拍照。
- 按规格比例预览。
- 背景色：蓝底、红底、白底、浅灰。
- 智能换底：本机色键或可选 API。
- 自定义尺寸：输入像素宽高，校验宽高比 1:1–1:2。
- 生成证件照。

验收：

1. 未选图时生成按钮不可用。
2. 选图后可按规格比例预览。
3. 切换底色后预览更新。
4. 生成后进入结果页，显示规格、像素、文件大小、背景色。

### 5.4 证件照结果（P0）

- 展示成品图与信息。
- 保存到相册/下载。
- 重新制作。
- 演示模式提示（未真实换底时）。

### 5.5 修改 KB（P0）

- 选图、输入目标 KB。
- H5 画布二分质量压缩；小程序逐级压缩。
- 显示原图/压缩后大小与质量。
- 保存压缩图。

验收：目标 50 KB 时，输出尽量 ≤ 50 KB；达不到时提示。

### 5.6 换底色（P0）

- 选图、选目标底色、生成、保存。
- 与编辑页共用本机色键/API。

### 5.7 个税首页（P0）

- 4 个 tab：工资个税、年终奖、劳务报酬、更多。
- 工资：月度/年度切换、缴纳期数、工资、五险一金、专项附加扣除、计算。
- 年终奖：正推税后/反推税前。
- 劳务报酬：正推/反推 + 居民/非居民。
- 更多：9 个税目入口。

验收：

1. 输入 20000 / 3000 / 2000 / 11 月，当月个税 1000、税后 16000。
2. 切换年度后按 12 个月累计计算。
3. 年终奖与劳务报酬可正反算。
4. 任一输入为空时提示，不产生结果。

### 5.8 个税结果（P0）

- 应纳税额、税前/税后（月度时标注“本月”）。
- 应纳税所得额（月度累计时标注“累计”）。
- 适用税率、速算扣除数。
- 计算说明、税率表。
- 月度工资年度模式可查看每月明细。
- 重新计算。

### 5.9 专项附加扣除（P0）

- 子女教育、3 岁以下婴幼儿照护、继续教育、住房贷款利息、住房租金、赡养老人、大病医疗、个人养老金。
- 每月合计，保存后带回工资表单。

### 5.10 更多税种（P0）

- 稿酬、特许权使用费、个体工商户、承包承租、财产租赁、财产转让、利息股息红利、偶然所得、解除劳动合同。
- 通用表单按税目字段动态渲染，支持正推/反推。

## 6. 业务规则

- 证件照规格像素以原工程为准。
- 证件照默认本机处理，不主动上传。
- 个税按累计预扣法，起征点 5000 元/月。
- 年终奖单独计税：奖金 ÷ 12 定税率。
- 劳务报酬：居民 800/20% 费用扣除，非居民 20% 费用扣除。
- 计算结果仅供参考，最终以税务部门口径为准。

## 7. 非功能需求

- 首屏 ≤ 2 秒（4G）。
- 主包 ≤ 2 MB；当前实测约 290 KB。
- 无登录、无后端依赖。
- H5/微信小程序同一套代码。
- 照片与收入数据只存本机。
- 兼容微信基础库 ≥ 2.7.0（离屏画布）。

## 8. 指标

- 证件照生成成功率。
- 个税计算完成率。
- 保存/下载成功率。
- 首页 → 功能页转化率。
- 用户反馈的规格缺失与计算差异。

## 9. 风险与后续

| 风险 | 对策 |
|---|---|
| 色键对复杂背景效果差 | 接入 AI 抠图 API；增加手动擦除 |
| 小程序离屏画布兼容性 | 失败回退原图并提示；提高基础库版本 |
| 个税政策变化 | 税率/扣除配置化，及时更新 |
| 证件照订单/支付缺失 | 二期按需接回 |
| 图片隐私 | 默认本机处理；API 模式明确告知 |

后续：AI 抠图、证件照排版打印、订单/支付、更多税种、结果分享。
